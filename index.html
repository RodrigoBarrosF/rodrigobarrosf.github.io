PROJETO 02

Trex↗

Um jogo de corrida infinita inspirado no dinossauro do Chrome, desenvolvido com JavaScript e as bibliotecas p5.js e p5.play.

O código combina saltos, obstáculos aleatórios, pontuação, detecção de colisões e reinício de partida, com animações e efeitos sonoros.

O que o projeto explora

Estados de jogo, movimento de sprites e eventos de entrada: uma aplicação de JavaScript além das interfaces tradicionais.
