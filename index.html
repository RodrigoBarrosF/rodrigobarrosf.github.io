PROJETO 03 · INTERFACE + SERVIDOR

DRY FIT↗

Uma plataforma de academia com áreas de aluno, personal e administração, desenvolvida como projeto de portfólio.

Da interface à aplicação

Cadastro e login, perfis com preferências, chat, planos e vencimentos, acompanhamento de presenças e faltas. A versão conectada utiliza Node.js e SQLite para salvar os dados no servidor.

O que o projeto explora

Permissões por perfil, autenticação, regras de negócio e testes automatizados. Inclui uma demonstração para explorar os fluxos da academia.

↳ Pagamentos online e catraca aguardam integração. A demonstração utiliza simulações.
